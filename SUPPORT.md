# Support

AI Translator for Contentful is maintained by one person in their own time. Support is best effort, through GitHub only, with no guaranteed response time.

- **Questions and bugs:** open a GitHub issue with the question or bug report template. Include the version, backend (Cloudflare Worker, Azure Functions, AWS Lambda, or Contentful Function), Contentful plan, browser, and the message shown.
- **Feature ideas:** open a feature request. The app is deliberately limited to editor-initiated translation with review; see the [README](README.md).
- **Security issues:** follow [SECURITY.md](SECURITY.md), not a public issue.

Never post credentials, signing secrets, provider responses, or real entry content. Use synthetic text.

For problems with Contentful, a backend host, or a model provider, contact that service's support.
